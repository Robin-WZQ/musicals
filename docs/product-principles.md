# 页面与内容原则

记录日期：2026-10-04。以下约定来自用户对当前网站的逐项确认，适用于后续修改和新增音乐剧、歌曲。

## 页面结构

- 保持「音乐剧总页 → 作品曲目页 → 单曲学习页」三层入口。
- 总页使用作品的原专辑封面。每部剧有自己的曲目列表，每首歌有独立网址。
- 曲目页按指定播放列表顺序排列，保留中法文搜索和继续上次学习。
- 学习页左侧放 YouTube 播放器、歌曲资料和中文介绍，右侧放逐句歌词。
- 使用原唱播放，点击歌词、音标、空耳或释义均能跳到同一句；保留单句暂停、循环、调速和自动跟随。
- 《La gloire à mes genoux》的中文名固定为《荣耀向我俯首》。

## 每首歌的介绍

资料和正文以中文为主，保留法语歌名、演员原名作为对照。每首歌都有自己的介绍，包含以下内容：

1. **基本资料**：歌名、演唱者、角色、语言、所属音乐剧和发行年份。
2. **这首歌讲什么**：用几句话说清人物的心情、想法，以及歌词在表达什么。
3. **剧情里的这一幕**：交代人物此时遇到了什么、与谁有关、为什么唱这首歌。
4. **演唱者与角色**：介绍演员在剧中扮演谁，再补充有资料支持的演员或角色信息。

写作时先讲具体的人和事。句子自然、直白，让第一次接触这部剧的人也能读懂。用各曲自己的剧情说明歌意，把整部剧的概况留在作品页。

少用抽象评价、口号和模板套话。删去为了预先辩解而写的否定句，以及「不是……而是……」这类无助于介绍歌曲的对比。语法提示、歌名释义和处理数据的过程，不能代替歌曲介绍。

人物关系、演员名单和剧情位置依据剧本、演出资料等来源填写。资料来源保留在可展开的来源栏；将上传频道与实际演唱者、视频上传日期与歌曲发行年份分别记录。

字幕读取、校对过程、替换视频和时间轴状态等说明放在对应的来源提示或开发文档中。曲目页已删除的「按原播放列表顺序收录……交叉校正……保留旧名供搜索」说明段落保持删除。

## 字号与颜色

介绍、资料和操作文字使用已经放大的默认字号。法语歌词、音标、空耳和释义保持用户确认过的字号；调整界面文字时，单独核对歌词区，避免一起缩放。

当前字号（CSS px，浏览器缩放 100%）：

| 内容 | 桌面 | 手机（宽度不超过 720px） |
| --- | ---: | ---: |
| 左侧介绍正文 | 16 | 16 |
| 介绍小标题 | 18 | 18 |
| 中文歌名 | 28 | 25 |
| 歌曲资料、法语歌名、专辑、角色 | 14 | 14 |
| 演唱者 | 16 | 16 |
| 音标/空耳开关、图例提示 | 14 | 13 |
| 元数据、来源说明 | 13 | 13 |

歌词区保留的字号：

| 内容 | 宽屏（超过 1150px） | 较窄桌面（721–1150px） | 手机（不超过 720px） |
| --- | ---: | ---: | ---: |
| 法语歌词 | 24 | 21 | 19 |
| 音标 | 19 | 17 | 16 |
| 空耳 | 15 | 14 | 13 |
| 中文释义 | 13 | 13 | 12 |

法语歌词使用浅色，音标使用青色，空耳使用珊瑚色，中文释义使用金色。保留颜色对比和各层开关。联诵、连读用 `‿` 标注。

## 滚动与窗口适配

- 刚打开歌曲时，第一句从歌词区域顶部开始显示；播放第一句时也保持靠顶。
- 开启跟随后，从第二句开始，当前句滚到歌词区域中间。点击跳句和单句循环沿用相同位置规则。
- 隐藏或显示音标、空耳、释义后，当前句仍按上述规则定位。
- 桌面窗口缩小时，完整的底部控制栏留在可见区域，歌词区域随可用高度调整。
- 手机上让文字和按钮正常换行，避免横向溢出。
- 居中所需的上下空白使用可滚动的占位元素。大块纵向 padding 会限制 flex 区域收缩，曾造成底部控制栏被遮挡，应保持当前占位实现。

## 数据与兼容

- YouTube 提供原唱视频与原始字幕信息，人工校正的歌词、中文介绍和学习注释独立保存。
- 更换播放视频时保留原歌曲页 ID 和已有网址，用 `playbackVideoId` 指向实际视频，并配套记录该视频的时间轴。
- 完整录像按曲目拆分时，每曲可以使用独立的语义路由ID；这些ID从曲库白名单解析，实际播放器和缩略图使用真实 `playbackVideoId`。舞台版本、唱片发行年与本版演员分别记录。
- 自动刷新原始字幕时保留已经编辑好的歌词、介绍和注释。
- 用户提供的歌词数据按数据格式解析，保留原行 ID 和原音标以便对照；页面使用整理后的音标及中文空耳。接入四层数据后，默认回到左侧原唱、右侧学习卡片。
- 用户粘贴的时间对应歌词直接作为本场录像的时间依据，清除复制附带的时间单位、曲名和字幕署名；保留原文、原行号和时间点。一个时间点含多句时，块内分句切点记录为近似值，长句保留到下一条时间点，避免提前截断慢唱。
- 全剧录像内部的单曲使用绝对秒数存储播放位置，页面显示本曲相对时间；字幕匹配后拆分的切点保持近似标记。
- 文本校正、时间轴校对和演唱发音核对分别记录。近似切点在学习页用 `≈` 标注，状态随实际校对结果更新。
- 混入歌词或对白的德语、英语、意大利语插句使用该语言的参考读音；保留完整短句，避免按大写字母拆开问候语和人名。中文释义统一人名、角色与作品名，音乐术语按剧情翻译。
- 自动识别原文的残句可接入参考四层卡片，原始输入保留在数据档案中。《莫里哀》按用户2026-10-05新要求不显示「识别不清」等逐段标注；不因隐藏提示而把未确认的正文填成新歌词。参考发音不标为原唱听写。
- 《莫里哀》用户提供的654行完整歌词保留原行ID及原音标，校对后的完整版本单独保存。现场学习卡片依据原录像的删节与唱句顺序对齐，共625行；未在录像中出现的唱片段落不分配到对白中。分句切点保持近似标记，参考读音不等同于原唱逐音核听。
- 《莫里哀》仅在曲库中展示用户指定歌词学习页列出的16首歌曲，顺序沿用该页；《Rêver j’en ai l’habitude》采用现有终曲录像，不重复展示声学版。原45段时间输入保留归档。其他作品的曲目和介绍保持原状。
- 更新资源时同步维护 `assets/data.mjs` 的版本、HTML 中的脚本和样式版本，以及模块引用，确保浏览器读取本次发布的数据。

## 修改后的检查

内容修改核对歌名、人物、演员、剧情和来源。字号修改核对介绍与操作文字的实际大小，同时确认歌词区原有字号。

布局修改检查宽屏、普通桌面、低矮窗口和手机：控制栏完整、页面无横向溢出、第一句靠顶、后续当前句居中。测试窗口由大变小再恢复，避免只检查首次打开的尺寸。

保持 `npm run check`、现有相关测试和 GitHub Pages 部署通过，发布后核对线上文件。
# 原生字幕来源

最终学习页沿用用户确认的四层歌词卡片：法语原文、带联诵的音标、中文空耳、中文释义。原唱播放器默认留在左侧。

已有人工字幕的完整演出可按曲目时间范围接入，作为字幕与原唱的过渡入口。原生字幕在 YouTube 播放器内显示，本站保存时间点并提供分段重听。页面明确区分「分段」与已校对的「逐句」，按实际完成情况标注。手动放大播放器后，缩小窗口仍须显示底部控制；原有歌词字号保持不变。来源元数据刷新须保留每曲的路由、时长与时间范围。

单曲视频也可以使用自己的字幕时间点。自动字幕标为「法语字幕（自动）」，人工字幕按实际来源标注；自动识别与整秒转录分段分别记录校对状态。视频上传年份、作品首演年份、封面专辑发行年份分开保存，具体演出日期有来源后再填写。

能读取人工字幕文件时，保留文件中的毫秒时间和无字幕间隔。按视频章节分曲，跨章节条目各自裁剪，来源提示说明片段含相邻对白；章节时长作为舞台片段时长。毫秒精度、人工来源和本站文字校对分别标注。

用户提供分视频时间表时，按时间归零位置与原播放列表顺序对应；同一视频内重复起点合并，恰好等于视频结束的标记不生成空片段。更新时归档原分段，保存文件SHA256和处理报告。本地修改使用单独的本地资源版本，待用户要求发布后再更新线上。

导入已有字幕或四层学习 JSON 后，按歌曲保存在当前浏览器。刷新后恢复，换歌时分别读取；播放视频或曲目范围改变后跳过旧缓存。导出文件保留四层文字与原录像的绝对秒数，可再次导入。恢复本站字幕只清除当前歌曲的本地副本。浏览器无法保存时明确提示导出备份。导入内容不沿用本站字幕的校对标记。
